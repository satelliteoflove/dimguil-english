# docs

course of the project: how the engine works, what was translated and why, the review
logs, and how to build the patch. I've kept them because they show how things were worked
out, but they haven't been edited for reading the way the README has, and some of them
describe work that has since moved on.

The README, the changelog and the release notes are mine.
